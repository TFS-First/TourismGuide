# إضافة محاضرة لمواد التاريخ

هذا الدليل لصفحات المحاضرات في `history/` و`graeco-roman/` و`islamic-history/` و`modern-history/`. دروس **اللغة المصرية القديمة** تُضاف عبر `docs/ADDING_LESSONS.md` وملفات `src/lessons/`.

## قبل كتابة الصفحة

1. افحص `git status` والفرع، ولا تستبدل عملًا مفتوحًا في صفحة المادة.
2. اطلب صفحات المصدر والطبعة أو الملف المعتمد، ودوّن المصدر. لا تضف حقائق تاريخية بالتخمين.
3. استخدم صفحة محاضرة موجودة في **نفس المادة** أساسًا للتنسيق، وحافظ على روابط البوابة وفهرس المادة وصور المادة.

## بنية الأقسام المطوية

كل قسم من القاموس والاستزادة والتدريبات يبدأ **مغلقًا**. لا تضع `open` على العنصر الخارجي. استخدم هذه البنية في كل محاضرة جديدة:

```html
<section id="vocabulary" class="scroll-mt-36">
  <details class="course-fold">
    <summary dir="rtl">افتح قاموس ومصطلحات الدرس</summary>
    <div class="course-fold-body">
      <!-- بطاقات المفردات وآلية فتحها المفردة هنا -->
    </div>
  </details>
</section>

<section id="guide-briefing" class="scroll-mt-36">
  <details class="course-fold">
    <summary dir="rtl">للاستزادة: شرح المرشد السياحي بالإنجليزية</summary>
    <div class="course-fold-body" dir="ltr" style="text-align: left">
      <!-- النص الإنجليزي هنا -->
    </div>
  </details>
</section>

<section id="quiz" class="scroll-mt-36">
  <details class="course-fold">
    <summary dir="rtl">افتح تدريبات وأسئلة الدرس</summary>
    <div class="course-fold-body">
      <!-- أسئلة الاختيار من متعدد والتصحيح هنا. تُضاف أسئلة صح أو خطأ والمقال تلقائيًا من بنك الأسئلة المشترك. -->
    </div>
  </details>
</section>
```

قد تحتوي بطاقات المفردات على عناصر `<details>` داخلية؛ هذا لا يغني عن طيّ قسم `#vocabulary` كاملًا. أبقِ معرّفات الأقسام على `<section>` حتى يستطيع `assets/course-ui.js` فتحها عند الانتقال عبر الرابط المباشر.

أضف إلى `<head>`: `<link rel="stylesheet" href="../assets/course-ui.css">`، وقبل `</body>`: `<script src="../assets/course-ui.js" defer></script>`. استخدم شريط `course-header` الثابت وقائمة `course-mobile-nav` ومحاور الدرس كما في المحاضرات القائمة.

## اختبار الذات في كل محاضرة

ضع قسم `#quiz` بعد الشرح وقبل التنقل إلى المحاضرة التالية، وأبقِ أسئلة الاختيار من متعدد داخل القسم المطوي. أضف مدخلًا باسم `اسم-المجلد/lecture-XX` في `assets/course-questions.json`. يعرض `assets/course-ui.js` من هذا المدخل قسم **صح أم خطأ؟** ثم قسمًا مستقلًا **للأسئلة المقالية** بعد أسئلة الاختيار. لا تنقل نصوص الأسئلة المقالية إلى الاختبار الآلي؛ يراجع الطالب إجابته بنفسه.

```json
"history/lecture-05": {
  "source": "اسم المرجع، الطبعة، الصفحات أو رابط ملف المحاضرة المعتمد",
  "trueFalse": [
    { "statement": "عبارة تاريخية قابلة للحكم", "answer": true, "explanation": "تعليل موجز موثق من المصدر" }
  ],
  "essay": [
    { "question": "سؤال يطلب شرحًا أو مقارنة أو تحليلًا", "answer": "نقاط الإجابة النموذجية المستندة إلى المصدر" }
  ]
}
```

اكتب `answer` في الصح والخطأ قيمة منطقية `true` أو `false`. يبقى `#quiz` مغلقًا عند تحميل الصفحة، وتبقى كل إجابة مقالية داخل `<details>` مغلقة حتى يضغط الطالب «اعرض الإجابة النموذجية». راجع الوقائع وصياغة الإجابات على صفحات المرجع والطبعة المعتمدة؛ لا تولّد أسئلة أو إجابات بتخمين معلومات من الذاكرة. أضف **٦ أسئلة صح أو خطأ و٤ أسئلة مقالية** لكل محاضرة. اشرح في تعقيب كل إجابة السبب التاريخي مباشرة، وتجنب الإحالة إلى «المحاضرة» أو «الدرس» بدل شرح المعلومة.

في `graeco-roman/` لغة الامتحان الإنجليزية: اكتب أسئلة الاختيار والخيارات والتعقيب بالإنجليزية، وأضف إلى كل بند في بنك الصح والخطأ `statementEn` و`explanationEn`، ولكل سؤال مقالي `questionEn` و`answerEn`. تبقى الحقول العربية ترجمة للمراجعة فقط؛ يعرضها المكوّن المشترك بعد إجابة الصح والخطأ أو داخل طيّ الإجابة المقالية. في الاختيار من متعدد أبقِ مفاتيح `q1`…`q10` و`ans` كما هي، وأضف `expEn` للتعقيب الإنجليزي وطيًّا عربيًا للسؤال والإجابة لا يظهر إلا بعد التصحيح. تأكد أن الإنجليزية LTR والعربية RTL، وألا تظهر الترجمة قبل محاولة الإجابة.

`assets/course-questions.json` هو مصدر بنك الأسئلة؛ شغّل `npm run build` ليولّد `assets/course-questions.js` ويرفع الملفين معًا. يحمّل مكوّن العرض ملف JavaScript دون `fetch` حتى تظهر الأسئلة عند فتح ملفات HTML مباشرة من مجلد المشروع عبر `file://` وكذلك على GitHub Pages. لا تنقل ملف محاضرة وحده خارج مجلده؛ يجب أن يظل مجلد `assets/` في موضعه النسبي. شغّل `npm run check` للتحقق من عدد الأسئلة ومن حداثة الملف المولّد.

## تحقق قبل التسليم

- القاموس والاستزادة والتدريبات مغلقة عند فتح الصفحة، وتفتح وتغلق بالملخص العربي.
- روابط `#vocabulary` و`#guide-briefing` و`#quiz` تفتح القسم المقصود حتى عند فتح الصفحة بالرابط المباشر.
- النص الإنجليزي LTR ومحاذاته يسار، والعناوين والأزرار العربية RTL.
- لا تمرير أفقي زائد ولا محتوى خلف الشريط الثابت عند 320 و390 و768 و1280 بكسل.
- روابط الصفحات والصور نسبية وصحيحة؛ `npm run build` و`npm run check` و`npm test` ناجحة.
